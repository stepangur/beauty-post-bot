# Бот @beuty_post_bot: фото → готовый пост

Присылаете боту фото (одно или альбом) с заметками в подписи, в ответ получаете пост в стиле канала Beauty_obsession💄. Пост уже с разметкой: его можно переслать в канал («Переслать → без указания автора») или скопировать.

- Поправить пост: ответьте (reply) на него пожеланием: «короче», «убери вопрос в конце».
- Без фото тоже можно: пришлите заметки текстом.

Бот работает в фоне на этом компьютере и отвечает за секунды, пока компьютер включён. Сообщения, отправленные при выключенном компьютере, бот обработает после включения, если с момента отправки прошло меньше суток.

## Автономная работа
Бот работает сам, ничего запускать не нужно. В Планировщике заданий Windows создано задание **BeautyPostBot**: каждые 5 минут оно проверяет бота и запускает его, если он не работает (после включения компьютера, входа в систему, сбоя или обрыва интернета). Второй экземпляр бота запуститься не может.

Чтобы бот работал круглосуточно, компьютер не должен уходить в сон: Параметры → Система → Питание → «Переводить в спящий режим» → «Никогда». Выключение монитора боту не мешает.

- `stop_bot.bat` — остановить бота и выключить автоперезапуск.
- `start_bot.bat` — включить снова.
- `autostart_off.bat` / `autostart_on.bat` — удалить или заново создать задание в Планировщике.
- `config.txt` — токен, ключ Claude API, список допущенных пользователей. `bot.log` — журнал работы.

## Стиль
- `style.md`: описание стиля канала и правила. Можно редактировать, например добавить постоянную подпись в конце постов.
- `examples.txt`: 35 настоящих постов канала, по которым бот копирует манеру.
После правок перезапустите бота (`stop_bot.bat`, затем `start_bot.bat`).

`workflow-bot.yml` нужен только для варианта с GitHub Actions, при работе на компьютере его можно удалить.
