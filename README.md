# Бот @beuty_post_bot: фото → готовый пост

Присылаете боту фото (одно или альбом) с заметками в подписи, в ответ получаете пост в стиле канала Beauty_obsession💄. Пост уже с разметкой: его можно переслать в канал («Переслать → без указания автора») или скопировать.

- Поправить пост: ответьте (reply) на него пожеланием: «короче», «убери вопрос в конце».
- Без фото тоже можно: пришлите заметки текстом.

## Как работает
Бот круглосуточно работает на GitHub Actions (вкладка **Actions**). Один запуск длится ~5 ч 45 мин, затем его сменяет следующий: расписание запускает workflow каждый час, лишние запуски ждут в очереди. Компьютер для работы бота не нужен.

Секреты (Settings → Secrets and variables → Actions): `TELEGRAM_TOKEN`, `ANTHROPIC_API_KEY`, `ALLOWED_USER_IDS` (кому можно пользоваться ботом).

Если бот молчит: Actions → beauty-post-bot → **Run workflow**.

## Стиль
- `style.md` — правила стиля канала по рубрикам. Можно править прямо на GitHub.
- `examples.txt` — 50 настоящих постов канала по рубрикам, по которым бот копирует манеру.
После правок на GitHub нажмите Cancel у текущего запуска в Actions и затем Run workflow, чтобы бот подхватил изменения.
